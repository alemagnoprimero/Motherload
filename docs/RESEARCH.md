# Original reference investigation

Initial inspection 2026-10-24; subsequent work is recorded below and in [current project status](PROJECT.md). Findings describe **this identified syndicated build**, not every release of Motherload. No original scripts, artwork, audio, or SWF are committed or bundled in the remake.

## Provenance and verification

- Publisher starting point: https://www.xgenstudios.com/play/motherload. Initially network-blocked; after allowlist update the proxy returned HTTP 503 with upstream `CERTIFICATE_VERIFY_FAILED`. TLS verification was preserved. Publisher-hosted byte-for-byte comparison remains unresolved.
- Listing: https://www.crazygames.com/game/motherload (HTTP 200). Its embedded `__NEXT_DATA__.props.pageProps.game` identifies developer XGen Studios, technology `ruffle`, and `loaderConfig.swfLocation` below.
- Direct file: https://files.crazygames.com/motherload/1/motherload_2017.swf (HTTP 200 over verified HTTPS).
- SHA-256: `4d480aec3dde7de7e3da54a594398388fd3a03f71eefd63668a94ff015ed928d`.
- Download: 4,068,041 bytes. Header: `CWS`, SWF version 8, declared and measured uncompressed size 4,580,235 bytes; 42 fps, 25 root timeline frames.
- JPEXS 26.4.0 exported 523 scripts successfully. Root `frame_1/DoAction.as:2240` sets version `0.934 (MC)`. Offline storage namespace is `miniclipxgenml`.
- Ruffle 0.7.1 displayed the title screen, XGen Studios / Miniclip branding, New Game / Load Game / Instructions, and an advertisement to buy the separate **Goldium Edition**. This supports identification as the free Miniclip edition. It does not prove the downloaded bytes equal XGen's original 2004 distribution; the filename's 2017 suffix is not a verified release date.
- Screenshots from the current run are under ignored `artifacts/original-ruffle.png` and `artifacts/original-interaction.png`.
- JPEXS archive was fetched from its official GitHub release over verified HTTPS. Observed SHA-256: `56ce960aeafc7caf034e2052ba49f878a883f7c7ca690da6eeffca9587b5e4b9`. This is a reproducibility pin, not an independently signed publisher checksum.

## Provisional remake decisions — first checkpoint (superseded below)

The first milestone preserves the loop and input directions, not numerical or physics parity. `src/model.ts` is independently implemented from the brief; none of the decompiled scripts is imported or copied into the game.

- Deterministic 24 × 100 grid, 32-pixel cells; depth displayed in meters, 10 m per row. Four guaranteed starter minerals make the first upgrade reachable quickly.
- Simplified grid movement with interpolated rendering, upward thrust, gravity, fall damage, downward/side drilling. No mass-based acceleration, radiator, engine upgrades, consumables, boss, or surface flight above the base row yet.
- Iron $25, Gold $75, Emerald $180, Diamond $400. Starting credits $60; fuel/hull 100; eight cargo slots.
- Drill duration .65 seconds (stone 1.2), divided by `1 + drillLevel × .55`. Movement consumes .15 fuel/cell, upward thrust .4; drilling 1.5/cell plus underground idle .08/second. Ordinary drilling wears .6 hull; magma damages 30; falls over three cells damage 5 per extra cell.
- Three upgrades per system, priced $100/$250/$600. Each tank/cargo/hull level adds 50 fuel / 6 slots / 40 max hull. New capacity requires buying service to fill it.
- All services available anywhere at surface depth 0 m. Refueling $1/unit; repair $0.70/unit, whole-credit rounded payment.
- Recovery loses cargo and 20% credits, restores 50% hull and fuel. A forgiving mechanism to prevent unrecoverable prototype states.
- Versioned localStorage saves include **every terrain cell**, position, credits, cargo, fuel, hull, upgrades, seed, mined count, best depth. Saves are device/browser/origin-specific, not compatible with Flash saves. Partial drill progress and motion interpolation are transient.

## Hands-on follow-up: movement and side drilling

The first checkpoint's Ruffle validation reached the title/menu screens; it did **not** establish hands-on gameplay parity. The follow-up entered the actual game, dismissed the opening transmission, drilled down, drilled left across supported terrain, collected Ironium in the interactive session, and used Up + Right together to fly through the excavated cavity. The repeatable capture script now enters Instructions and closes it before selecting New Game, which reliably activated this build's menu in these Ruffle sessions.

The captured repeat run shows depth changing from approximately −49 ft after downward excavation to −50 ft after lateral excavation, then −37 ft after diagonal flight. The independently generated terrain differs between runs. These are observed screen states, not measurements of exact physics constants. Screenshots: `artifacts/original-mining.png`, `original-lateral.png`, and `original-diagonal.png`.

The original preserves horizontal steering during upward thrust. Its side-drill entry checks ground/tread support and excludes Up; a floating rig against a wall does not automatically start drilling. A ledge can be above a deeper shaft: "grounded" does not mean "at the deepest point in the mine." Once drilling starts, the animation advances toward the chosen tile rather than changing targets on every gravity step. Static citations: `frame_1/DoAction.as:745–858`, `:2470–2646`; `DefineSprite_430/frame_10–13/DoAction.as`.

Ruffle emitted repeated `non-registered character tileEmpty` console diagnostics during gameplay and two HTTP 404 console messages in the repeat capture. The game visibly remained playable, and no JavaScript page errors occurred. Emulation is therefore useful qualitative evidence, not proof of exact native Flash behavior or timing. The capture script reports console diagnostics separately and explicitly requires screenshot inspection rather than presenting title loading as a gameplay assertion.

### Changes informed by the follow-up

- Replaced tile-step travel with continuous, bounded acceleration, gravity, damping, and collision checks. Cargo count adds a provisional mass factor; it is not the original mineral-mass formula.
- Up and horizontal input operate together. Touch tracks each pointer independently, so releasing one finger does not release the other direction.
- Side drilling starts on supported terrain, including intermediate ledges. Unsupported drilling displays an explicit explanation instead of starting/resetting progress as the rig falls.
- A started cut holds its selected tile and completes after key release. Up cancels the cut as a deliberate responsiveness aid; this cancellation is not claimed to reproduce the original animation logic.
- Fall damage occurs on impact, not when upward thrust merely arrests a fall.
- Saves use schema 2 with fractional positions; schema 1 saves migrate without changing terrain, inventory, money or upgrades. The storage key remains `motherload.frontier.v1` so existing installations find their save.

Remaining fidelity work: tune acceleration/thrust/braking with measured play traces, mineral-weight differences, original drill/depth timing, generated cave geometry, and physical Android testing. The earlier provisional grid-motion description above records the first checkpoint; this section supersedes it for movement and position saving.

## Expanded expedition milestone — 2026-10-26

The remake now adopts the ten-mineral roster, mineral weights, starting resources, original drill/engine/tank/cargo/hull tables, fuel price and repair price documented above. Engine upgrades affect the simulation, and ordinary soil cuts no longer damage hull. The world now has seeded cave pockets and depth-sensitive deposits.

Generation uses a bounded 24 × 100 world, assisted starter veins, compressed depth bands and a guarantee that every mineral survives cave carving; those are deliberate remake choices, not a copy of the original random generator. Fuel uses nominal 42 fps conversion of the inspected per-frame quantities, with elapsed-time parity still unmeasured. Full terrain saves remain an explicit user requirement. See [PROJECT.md](PROJECT.md) for the complete current behavior, migration policy, validation and remaining deviations.
